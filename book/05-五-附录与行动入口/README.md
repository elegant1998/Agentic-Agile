# 第五部分｜附录与行动入口

前四部分完成了从问题、架构、控制回路到组织落地的完整论述，第五部分则把这些内容收束为可以随时查阅和立即使用的行动入口。它不是与正文脱节的资料堆积，而是本书的“操作台”：当读者需要回顾价值观、选择模板、定位课程、查找术语或启动第一个任务时，可以从这里快速进入。

本部分首先给出 Agentic Agile 宣言与开源治理资产速查，帮助读者从原则直接找到模板、脚本和 Dashboard；随后提供图书与四门新版 Portal 课程的学习地图，说明诊断、真实任务、组织重构和 FDE 现场实践之间的关系；术语表、五道门、贯穿案例和常见质疑，则分别承担概念对齐、机械检查、端到端示范与异议澄清的作用。

最后的四大动态工件实战指南面向真正准备动手的读者：可以从一个真实但边界可控的任务开始，建立意图图谱与意图契约，配置约束，运行 SCOPE-V，生成 Evidence Bundle，采集契约级遥测并观察全局 Dashboard。附录不要求按顺序阅读，可以按照“理解概念—查找资产—完成闭环—进入课程或组织试点”的需要反复使用。

本书最终希望留下的，不是一套只能被复述的概念，而是一种可以被验证的行动方式：先让意图可判定，再让边界可执行；先让执行产生证据，再让人和系统基于证据作出裁决；最后用遥测和真实结果决定哪些方法值得保留、扩展或修正。
