# 附录 C｜图书与课程学习地图

本书的学习延伸分为线下工作坊和 Portal 在线课程两条路径。两者共享 Agentic Agile 的价值观与操作系统主干，但承担不同任务：线下强调现场共创、真实组织决策和工程突围；在线强调可重复的 Mission、学习证据和个人能力形成。章节引用只说明能力关系，不把某个历史模块号当成永久接口。

### C.1 线下工作坊延伸

新版《Agentic Agile（智能体敏捷）：从碳基协作到硅基自治——AI 时代研发组织重构与转型沙盘》以 AI First / AI Native 和四维重构为主线：第一天建立转型事实、重构人员/组织/流程/工具，第二天在真实或明确标记为 SIMULATION 的工程任务中完成突围、证据裁决和组织扩展判断。工作坊的最终产物不是一份口号式转型规划，而是一张连接真实价值流、任务证据和首轮行动的转型画布。

### C.1.1 书籍章节与线下工作坊映射

线下工作坊不是每章都重复出现的课程广告，而是本书方法的集中实践场。章节与工作坊的对应关系如下：

| 图书章节 | 线下工作坊对应实践 |
|---|---|
| 第 1–4 章 | 第一天：AI 转型事实、三大理论基石、Agentic Agile 宣言与 AI First / AI Native 讨论 |
| 第 5–8 章 | 第一天：操作系统总装图、四维转型设计、人员与组织重构；第二天：责任单元、动态工件和自治机制 |
| 第 9–15 章 | 第二天 Phase 2–4：SCOPE-V、意图契约、约束矩阵、Work Graph、TDD、故障修复与 Evidence 裁决 |
| 第 16–20 章 | 第一天：价值与效能遥测；第二天：Dashboard、发布裁决、既有系统 Recon、知识回写与跨模块扩展 |
| 第 21–24 章 | 第一天：四维转型画布；第二天 Phase 5：企业首轮转型判断、风险裁剪、回滚和组织扩展边界 |

因此，正文中的“延伸实践”只在章节确有必要时提示工作坊动作；完整的线下映射统一放在这里，避免在每章重复同一段说明，也避免读者误以为线下工作坊只是在线课程的实体版。

### C.2 四门 Portal 在线课程

Portal 网址: http://agentic.iloveagile.me

| Course | 定位 | 核心产出 |
|---|---|---|
| 《Agentic Agile 免费认知课：AI 转型为什么不是工具升级》 | 免费认知 | 理解为什么局部工具提效不会自动转化为组织提效，并建立 AI First / AI Native 的判断框架 |
| 《Agentic Agile 3-4-3 基础课：跑通第一次受控自治》 | 方法与工程入门 | 在本地 AI 工具与 343 Skill 中完成一次真实工程任务，留下契约、约束、执行证据和裁决结果 |
| 《Agentic Agile 组织转型进阶：构建人机协同研发操作系统》 | 组织级转型 | 把一次任务闭环扩展为责任单元、协作协议、授权边界和组织级行动 |
| 《Agentic Agile FDE 进阶：从客户现场到企业级生产交付》 | 客户现场与生产交付 | 在客户现场或明确标记的模拟环境中完成事实、场景、责任、价值流和交付证据闭环 |

四门课不是传统的“看完视频再做题”。每个 Mission 都应在本地 AI 工具中完成，按游标逐题交互，自动运行规定的动手实验，产出脱敏学习证据和可下载的阶段作品。Portal 负责门禁、进度、预览和显式上传；Learning Skill 负责本地引导、反馈、证据落盘；343 Skill 只在课程明确授权的工程任务中承担治理与验证。

### C.3 推荐路径

```text
免费认知课：先看清转型断点
        ↓
3-4-3 基础课：亲手完成一次任务级受控自治
        ↓
组织转型进阶：把任务闭环扩展为组织与责任网络
        ↓
FDE 进阶：在客户现场或模拟现场完成迁移
        ↓
线下工作坊：把个人能力转成组织级转型决策
```

这不是强制的商业购买顺序，而是能力形成顺序。读者也可以按职责进入：管理者从免费认知课和工作坊开始，工程人员从 3-4-3 基础课开始，组织与平台负责人重点看组织转型进阶，FDE 和交付团队重点看 FDE 进阶。无论从哪里进入，都必须回到真实任务、真实证据和真实责任，而不是停留在概念认同。

### C.5 书、Skill、Portal 的边界

```text
图书：建立价值观、模型和判断框架
Learning Skill：在本地 AI 工具中陪伴学习、提问、反馈和生成证据
343 Skill：把真实工程任务变成可治理、可验证、可回滚的运行闭环
Portal：提供课程目录、Mission 门禁、学习进度、证据预览和显式同步
线下工作坊：把个人闭环带回组织，完成四维转型与扩展裁决
```

课程和 Skill 会持续演进，因此正文使用面向读者的课程名称，不固化旧模块编号或历史 URL。具体 Mission 版本、Skill 版本和资源下载入口以 Portal 与开源仓库当前发布信息为准。
